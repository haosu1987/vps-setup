# VPS 首次安装与配置

先读[架构与操作顺序](../../README.md)。本文适用于新机器；现有服务器先用 proxyctl doctor 审计，不重复安装。实际命令中的端口、地址和路径以私有 OPERATIONS.md 为准，本文不包含可公开部署值。

## 准备与安装

在 Linux x86_64 VPS 上核对现有 SSH、资源、监听与主机/云防火墙，保留另一个可恢复的 SSH 会话。已有数据先备份，不重置整机规则。按 maintainer.md 填写本机私有参数并生成新的工作区；需要下载材料时显式选 --fetch-vendor，核对固定摘要后才执行。

进入生成工作区，在自己的交互终端运行：

```bash
sudo bash scripts/proxy/admin-preflight.sh
sudo bash scripts/proxy/install-panel.sh
```

包装器只接受新安装和交互终端，检测已有安装就停止。固定安装器为官方 3X-UI v3.11.0；它可能安装依赖和服务，因此要由你明确执行。选择 SQLite、自定义私有手册中的端口、仅 SSH 隧道访问的 HTTP 方式、绑定回环；不启用自动 Fail2ban 配置。

安装生成的管理账号、密码与随机路径只保存在自己的密码管理器。安装完成核对服务 active 和管理面仅回环监听，安装本身尚未创建代理入站。

## 管理面和订阅

在 Mac 按 OPERATIONS.md 打开 SSH 本地端口转发，浏览器访问对应的本机回环端口及随机路径。隧道关闭后无法登录管理页面是正常的，不影响已经配置的代理数据连接。

面板默认订阅需要单独关闭；只绑定管理回环地址并不会关闭订阅。进入面板设置关闭订阅并应用，核对订阅监听消失、管理面仍仅回环。不要把公网开放管理面当作排障步骤。

## 创建代理入口

在面板创建 VLESS + TCP/RAW + REALITY 入站，为每台设备创建独立客户端并选择 Vision。目标、SNI、公钥和 short ID 对齐客户端；VPS 连接地址与 SNI 分开填写。服务端私钥不导出。具体界面见[入站配置](reality-inbound.md)。

服务端 routing.domainStrategy 设 IPOnDemand，保留非公网目标阻断，既检查 IP 字面量也验证域名解析后指向私网的请求。生产配置由面板管理，不直接编辑它生成的 JSON 或数据库。

按实际业务需求增量放行代理入站，保留 SSH，不开放管理/订阅端口。云规则另查，不能只看服务器防火墙推断公网已通。

## 审计与交付

```bash
sudo bash scripts/proxy/proxyctl.sh doctor
```

输出检查协议、REALITY/Vision、路由、配置语法及资源。root 结构审计不是完整代理测试，还需要在 Mac/iPhone 使用真实凭据确认出口和目标可达，检查错误凭据、私网阻断、停止恢复及独立撤销。

包内核心与既有兼容基线可能不同。已有确认基线为 Xray 26.10.31；需要更新时按维护手册先备份、经面板执行、再复验，不在安装后静默升级。日志、备份、单入站 BBR 和重启验收见[维护手册](server-maintenance.md)。

停止服务会中断全部客户端，在已有授权范围内执行；卸载前保全备份、核对移除范围。仅删除本方案实际创建且有记录的规则，不批量清理防火墙。
